# How to do the thing

1. Download the zip file.
2. Extract the zipfile.
3. Open MicroDash-master -> MicroDash-master -> MicroDashBackend in terminal.
   - If you don't have node installed, install node.
4. In the terminal type: node app.js
5. Open MicroDash-master -> MicroDash-master -> MicroDashFrontend -> micro-dash in another terminal.
6. Enter: npm install
7. Enter: npm run dev
8. Open MicroDash-master -> MicroDash-master -> MicroDashFrontend -> micro-dash in a third terminal.
9. Enter npm
